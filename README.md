# 🎬 Media Tracker

Media Tracker, film ve dizi takibini kolaylaştıran modern, kullanıcı dostu ve tamamen tarayıcı tabanlı bir web uygulamasıdır.  
İzlemek istediğin içerikleri listeleyebilir, izlediklerini işaretleyebilir, puan verebilir ve filtreleyebilirsin.

---

## ✨ Özellikler

- 📋 **İzlenecek & İzlenen listesi**
- ⭐ **5 yıldızlı puanlama sistemi**
- 🔍 **Anlık arama özelliği**
- 🎭 **Tür & kategori filtreleme**
- 🌙 **Dark Mode (Gece Modu)**
- 🌍 **Türkçe / İngilizce dil desteği**
- 💾 **LocalStorage ile veri kaydı (sunucusuz çalışma)**
- 📱 **Responsive tasarım (mobil uyumlu)**

---

## 🎨 Kullanılan Teknolojiler

- HTML5
- CSS3 (Gradient, Flexbox, Grid)
- Vanilla JavaScript
- LocalStorage API

---

## 🚀 Nasıl Çalıştırılır?

1. Projeyi indir veya kopyala
2. `index.html` dosyasını aç
3. Tarayıcıda kullanmaya başla 🎉

---

## 🧠 Nasıl Çalışır?

- Eklenen filmler/diziler `watch later` listesine kaydedilir
- “İzlendi” butonuyla içerik diğer listeye taşınır
- Puanlama sistemi ile izlenen içerikler değerlendirilebilir
- Tüm veriler tarayıcı hafızasında (LocalStorage) saklanır

---

## 📸 Özellik Detayları

### 🌙 Dark Mode
Kullanıcı deneyimini artırmak için gece modu desteği içerir.

### 🔍 Arama
Başlık ve kategoriye göre anlık filtreleme yapar.

### 🌍 Dil Sistemi
Türkçe ve İngilizce arasında anında geçiş yapılabilir.
